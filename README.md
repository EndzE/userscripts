# Userscripts

A collection of useful userscripts for browser enhancement.

## Scripts

### ByXatab - Steam & SteamDB Buttons
Adds Steam and SteamDB buttons to game pages on [byxatab.com](https://byxatab.com/) styled to seamlessly match the site design in both light and dark themes.

- **File:** [`byxatab-steam-steamdb-buttons.user.js`](byxatab-steam-steamdb-buttons.user.js)
- **Greasy Fork:** [ByXatab - Steam & SteamDB Buttons](https://greasyfork.org/en/scripts/604250-byxatab-steam-steamdb-buttons)
- **Install:** [Direct Install](https://raw.githubusercontent.com/EndzE/userscripts/main/byxatab-steam-steamdb-buttons.user.js) · [Greasy Fork](https://greasyfork.org/en/scripts/604250-byxatab-steam-steamdb-buttons)
- **Features:**
  - Extracts Steam App ID from game pages with automatic caching via ScriptCat / Tampermonkey storage.
  - One-click navigation to Steam Store and SteamDB pages.
  - Native styling for both light and dark modes.
