# Userscripts

A collection of useful userscripts.

## Scripts

### ByXatab - Store Buttons
Adds Steam, Epic Games, and GOG buttons to game pages on [byxatab.com](https://byxatab.com/) styled to seamlessly match the site design in both light and dark themes.

- **File:** [`byxatab-store-buttons.user.js`](byxatab-store-buttons.user.js)
- **Install:** [Direct Install](https://raw.githubusercontent.com/EndzE/userscripts/main/byxatab-store-buttons.user.js) · [Greasy Fork](https://greasyfork.org/en/scripts/604250-byxatab-store-buttons)

### Givee.Club - Card Dimmer
Adds a top-right toggle button on game cards to dim or undim them, preserving hidden cards across reloads and syncing in real time across open tabs.

- **File:** [`givee-club-card-dimmer.user.js`](givee-club-card-dimmer.user.js)
- **Install:** [Direct Install](https://raw.githubusercontent.com/EndzE/userscripts/main/givee-club-card-dimmer.user.js) · [Greasy Fork](https://greasyfork.org/en/scripts/604854-givee-club-card-dimmer)

### YouTube - Commenter Subscribers
Displays the commenter's subscriber count next to their username on YouTube.

- **File:** [`youtube-commenter-subscribers.user.js`](youtube-commenter-subscribers.user.js)
- **Install:** [Direct Install](https://raw.githubusercontent.com/EndzE/userscripts/main/youtube-commenter-subscribers.user.js) · [Greasy Fork](https://greasyfork.org/en/scripts/604261-youtube-commenter-subscribers)

### YouTube - Default To Live Chat
Automatically switches YouTube chat from Top Chat to Live Chat, with minimal CPU usage.

- **File:** [`youtube-default-to-live-chat.user.js`](youtube-default-to-live-chat.user.js)
- **Install:** [Direct Install](https://raw.githubusercontent.com/EndzE/userscripts/main/youtube-default-to-live-chat.user.js) · [Greasy Fork](https://greasyfork.org/en/scripts/604260-youtube-default-to-live-chat)

### YouTube - Livechat GoToChannel
Restores the "Go to channel" option in YouTube live chat with instant context menus, hover prefetching, and debounce bypass.

- **File:** [`youtube-livechat-gotochannel.user.js`](youtube-livechat-gotochannel.user.js)
- **Install:** [Direct Install](https://raw.githubusercontent.com/EndzE/userscripts/main/youtube-livechat-gotochannel.user.js) · [Greasy Fork](https://greasyfork.org/en/scripts/604353-youtube-livechat-gotochannel)
